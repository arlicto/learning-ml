# Learning ML

A collection of beginner-friendly machine learning exercises using Python and Jupyter notebooks.

## Contents

- `hearts.ipynb` - Heart disease data analysis and prediction
- `insurance.ipynb` - Insurance dataset analysis
- `ml_all_in_one.ipynb` - Combined machine learning practice
- `stat.ipynb` - Statistics exercises
- `csv_files/` - Datasets used by the notebooks
- `src/learning_ml/` - Python package source code

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Setup

Clone the repository:

```bash
git clone https://github.com/arlicto/learning-ml.git
cd learning-ml
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the required packages:

```bash
pip install jupyter pandas numpy matplotlib seaborn scikit-learn
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook and run the cells.

## Datasets

The datasets are stored in the `csv_files/` directory:

- `heart.csv`
- `insurance.csv`
